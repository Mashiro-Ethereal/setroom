# 乐队曲库 · Setroom

一个在 Mac 上运行的单人乐队曲库。所有界面和数据均在本机，不需要联网、账号或云服务器。

## 启动和退出

1. 双击本文件夹里的 **启动曲库.command**。
2. 启动窗口出现后，浏览器会自动打开管理页面。也可以点击窗口里的“打开管理页面”。
3. 修改后点击“保存”。页面关闭前如有未保存的修改，会提醒你。
4. 完成管理后，点击网页左下角的 **退出应用**，或启动窗口里的 **退出应用**。关闭启动窗口也可以停止服务。

退出后，后台服务和启动窗口都会结束，数据文件仍然保留。只关闭浏览器标签页不会停止服务；可以从启动窗口重新打开页面。重复双击启动文件会打开已经运行的应用，不会启动第二个服务。

如果 Terminal 留下一个显示“进程已完成”的窗口，可以直接关闭；它不代表曲库服务仍在运行。

运行需要 Python 3.10 或更新版本及 Tk。当前电脑已具备，无需安装项目依赖。其他 Mac 可以从 [Python 官网](https://www.python.org/downloads/macos/) 安装；目前启动器针对 macOS。

## 曲库

- 点击“新增曲目”，填写名称、版本、语言和状态。
- 同一首歌的不同版本分别建档；版本留空时保存为“原版”。
- 多种语言用逗号或顿号分隔，例如 `国语、粤语`；器乐曲可填写“纯音乐”。
- 状态为“可演 / 大饼 / 取消”。“已演过”根据已完成的演出歌单自动计算。
- 已被任何演出引用的曲目不能直接删除，可以改为“取消”。
- 搜索名称或版本，并按语言、状态、“只看已演过”筛选。
- 点击表头“曲目名称”或“版本”，在 A–Z / Z–A 之间切换排序；不区分英文大小写，数字按数值排列，中文及日文使用中文区域的文字排序规则。
- “演出经历”表头的下拉框可按演出数量（多到少 / 少到多）或最近演出日期（新到旧 / 旧到新）排序。按日期排序时，尚未演出的曲目始终在末尾。
- 排序与筛选可同时使用；切换页面后保留本次排序，刷新网页后恢复默认顺序。

## 未来演出

- 填写演出日期、名字、主办方、地点、语言。主办方和地点不确定时可先留空。
- 在“从曲库选曲”中添加曲目，用上下按钮调整顺序，填写本场备注。
- 默认选择可演曲目，勾选“包含大饼”后可把准备中的曲目加入规划。
- 已取消曲目不会新增到规划歌单；已加入的曲目后来取消，会在歌单中提示。
- 到期未处理的演出显示“待确认”。不会仅因日期过去而自动归档。
- 结束后点击“核对歌单并完成演出”，确认实际曲目、顺序和备注，再点击“完成并归档”。未来日期或空歌单不能归档。
- 取消演出会保留资料；勾选“查看已取消”可找到并重新编辑为计划中。

## 历史记录

- 已完成演出显示实际歌单。之后编辑曲库名称、版本、语言或状态，都不会改写历史。
- 可以“补录历史演出”，从曲库添加实际演过的曲目，包括现在已经取消的曲目。
- “更正记录”可修改本场资料、歌单顺序和备注。历史条目下的“更正本场曲目文字”只修改这一场的归档文字。
- “复制为新演出”复制歌单和备注，再填写新日期。当前已取消的曲目不复制，版本文字使用曲库当前信息。
- 删除演出会删除本场歌单；不会删除曲库中的曲目。

## Excel 导出

- 曲库可导出全部或当前筛选结果：名称、版本、语言、状态。
- 单场演出可导出 Excel，含“演出信息”和“演出歌单”两个工作表。
- 歌单按演出顺序导出，包含版本、语言和备注；尚未完成的演出还包含曲目当前状态。
- 历史导出使用归档信息。文件名包含日期和演出名称。
- 文件会按浏览器下载设置保存，通常在“下载”文件夹。若想每次选位置，可在浏览器设置中启用“下载前询问保存位置”。
- 导出的 `.xlsx` 是独立文件，乐手无需安装本应用即可用 Excel、WPS 或 Numbers 查看。导出后如有修改，需要重新导出再发送。

## 备份与恢复

实际数据在 `data/songs.sqlite3`。请保留整个 `song_database` 文件夹，尤其不要删除 `data`。

在左下角“备份与恢复”中下载完整备份。建议另存到移动硬盘或云盘；同一块磁盘上的副本不能防止磁盘损坏。应用运行时请使用此按钮备份，不要直接复制正在写入的数据库文件。

恢复时选择本应用导出的 `.sqlite3` 文件。恢复会替换当前所有曲库和演出。应用先验证文件，再将当前数据库备份到 `data/backups/恢复前_时间.sqlite3`。恢复失败时不会用无效文件覆盖当前数据。恢复前的文件也可以再次选择恢复。

Excel 用于分享，不能用于恢复完整应用。第一版未提供 Excel 导入。

## 开发与排查

- `python3 launch.py`：启动本地控制窗口。
- `python3 app.py`：只运行服务，终端第一行输出访问地址；按 `Ctrl+C` 停止。
- `python3 -m unittest discover -s tests -v`：运行数据、导出及 HTTP 测试，使用临时数据。
- `node --test tests/test_sorting.cjs`：运行曲库排序与筛选测试，仅开发验证时需要 Node.js。
- `python3 app.py --data-dir /tmp/setroom-test`：指定独立测试数据库。
- 服务只监听 `127.0.0.1`，不开放局域网或公网访问。
- 多个标签页同时编辑同一记录时，会拒绝覆盖较新的保存。刷新后重新编辑即可；恢复数据也会使旧编辑窗口失效。
- 启动错误记录在 `data/app.log`。

代码结构：`store.py` 负责 SQLite 与归档规则，`app.py` 提供本地接口，`excel.py` 写出本应用使用的 XLSX 表格，`static/` 是页面，`launch.py` 控制服务生命周期。运行时仅使用 Python 标准库，无在线资源或 npm 安装步骤。
