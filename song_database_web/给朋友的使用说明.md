# 乐队曲库 · 简短使用说明

一个管理歌曲、演出歌单和排歌愿望的小工具。手机、电脑浏览器都能打开，不需要安装软件或注册 Cloudflare 账号。

**网站：https://krb.xiuhuizhang1004.workers.dev/**

## 第一次使用

1. 在登录页点击 **“申请创建乐队”**，填写乐队名称、联系人、联系方式和乐队标识。
2. 自行设置一个 **Key（登录口令）**，简单数字、文字或 emoji 都可以。
3. 提交后保存 **私密申请进度链接**，通过它查看审核结果；Key 也请自行保存。
4. 管理员批准后，用 **乐队标识 + Key** 登录。把入口、标识和 Key 私下发给本乐队成员即可一起使用。

乐队标识用于登录，需要 3–40 位小写字母、数字或中间的短横线，例如 `our-band`。审核结果在进度页面手动刷新查看，不会自动发邮件。

## 四个模块怎么用

- **未来演出**：填写日期、名称、主办方、地点和语言，从曲库选歌并调整顺序。演出结束后核对实际歌单，完成归档。
- **曲库**：添加、修改歌曲名称、版本、语言和状态（可演 / 大饼 / 取消）。建议先添加歌曲，再安排演出歌单。
- **愿望单**：记录想排的歌。“发起人”和“我也想排”直接填写名字，支持 emoji。确定要排时点击 **“加入曲库”**，歌曲会移入曲库，默认状态为“大饼”。
- **历史记录**：查看已完成的演出和实际歌单，也可以更正记录。

语言选项为 **“仅日语 / 全语种”**，按你们可演唱的语言范围选择。

## 分享与保存

- 曲库、愿望单和演出歌单都能 **导出 Excel**，方便发给乐手。
- **“备份与恢复”** 可下载完整 JSON 备份；Excel 用于分享，JSON 用于完整恢复。恢复会替换本乐队的数据。
- 数据保存在云端，修改后记得点击保存。关闭网页或电脑不影响其他成员使用。

## 关于账号和数据

每个乐队的数据独立，乐队成员共用 Key，都可以编辑本乐队内容。网站管理员可以查看和管理各乐队的数据。Key 和进度链接请私下保存，忘记 Key 或遇到问题可联系网站管理员。
