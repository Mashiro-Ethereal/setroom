# 多乐队版使用指南

网站：https://krb.xiuhuizhang1004.workers.dev/

## 你：网站管理员

打开 [网站管理员登录](https://krb.xiuhuizhang1004.workers.dev/login?admin=1)，使用独立的网站管理员 Key。本机 `.platform-access.txt` 保存了这个 Key，请只由你保管；它与 KRB 的共用 Key 不同。

登录后，“乐队与申请”页面会优先显示待审核申请。检查乐队名称、标识、联系人和联系方式，然后选择批准或拒绝。审核说明会显示在申请人的进度页面。批准后立即开通；拒绝后保持关闭。如果需要补充资料，可以通过申请人留下的联系方式联系。

已开通的乐队有“管理曲库与演出”入口，在新标签页打开其四个模块。你不需要知道他们的 Key。不同标签页固定对应各自的乐队，注意侧栏显示的乐队名称。

“设置”可修改名称、联系方式和启用状态。停用会阻止成员登录，保留全部数据，你仍可以管理；也可以重新启用。“重置 Key”可以替换乐队 Key，旧 Key 和旧登录随即失效。后台不能显示原来的 Key，请私下把新 Key 交给相应的乐队。Key 只需填写，不限制长度或字符组合，支持简单数字、文字和 emoji。

“删除乐队”会永久删除该乐队及全部歌曲、演出、歌单、愿望单和站内恢复前备份，同时使 Key 登录和申请进度链接失效。需要输入完整乐队名称确认，网站内无法撤销；如需保留资料，请先导出备份。其他乐队不受影响。删除后原标识可重新申请，但旧 Key 和旧会话不能访问新空间。

你也可以点击“创建乐队”直接开通空间，创建时自行填写资料和 Key，无需再审核。朋友乐队的愿望单默认自由填写。

## 朋友：申请与登录

1. 在登录页点击“申请创建乐队”。填写名称、联系人、联系方式、乐队标识和 Key。
2. 标识为 3–40 位小写字母、数字或中间的短横线，例如 `friend-band`。它用于登录且不能重复，当前版本创建后不能修改。
3. 确认已了解网站管理员可以查看和管理乐队数据，提交申请。
4. **保存提交后显示的私密进度链接，并自行保管 Key。** 本版本不自动发送邮件，进度页面点击“刷新进度”查看结果。
5. 获批后，点击“进入乐队”，用申请时设置的 Key 登录。成员不需要 Cloudflare 账号。

申请被拒绝后可联系网站管理员，或使用新的乐队标识重新申请。丢失进度链接可以联系管理员查询；忘记 Key 则请管理员重置。

乐队成员共用 Key，都可以编辑本乐队的数据，但不能进入其他乐队。该方式不区分具体操作人，愿望单也可以由伙伴代填。

## KRB 和朋友乐队的区别

KRB 标识为 `krb`，原有乐队 Key 继续可用；现有曲库与演出数据完整保留。

KRB 愿望单保留五位成员选项：🎸ko、🎸mu、🎤🐱、🎹伟、🥁钱。发起人单选，“我也想排”多选。

朋友乐队的“发起人”和“我也想排”都是文本框，支持 emoji。例如发起人填“🎸小明”，我也想排填“阿白、🥁小林”。发起人必填，“我也想排”可留空，不需要维护成员名单。

所有乐队都有未来演出、曲库、愿望单、历史记录。愿望“加入曲库”后默认“大饼”。语言选项均为“仅日语 / 全语种”。

## 导出和备份

Excel 仅导出当前乐队的数据，文字和 emoji 会保留。JSON 备份用于完整恢复，Excel 不能代替完整备份。

“备份与恢复”只影响当前乐队，不影响其他空间。新版备份会校验乐队归属，避免把其他乐队的文件误恢复进来。KRB 仍可恢复旧版网页 JSON 备份。恢复前会自动保留当前乐队最近一次恢复前的备份。

网站运行在云端，关闭网页、终端或你的电脑都不会关闭它。旧的本地 Python 版本仍然独立保留，不与云端自动同步。
